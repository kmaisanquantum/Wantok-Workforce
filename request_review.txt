I have refactored the fetchNearbyProviders function in WantokWorkforce.js to include a client-side fuzzy matching engine.

Key features:
- SYNONYM_EXTENSIONS map for stemming roots (e.g., 'law' matches 'Legal').
- Standardized search input with synonym root appending.
- Scoring-based fuzzy matching loop that handles:
    - Standard substring matches.
    - Typo handling using a lightweight distance check (allowing for 1-character differences).
    - Keyword fragment matching across name, role, bio, and skills.
- Graceful error handling and empty state management.

Verified clean build and syntax.
